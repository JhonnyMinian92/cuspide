🎨 Personalización de Botones Corporativos

Los botones del sistema usan la clase .btn-brand definida en assets/css/styles.css. Para cambiar el color corporativo de todos los botones a la vez, edita las variables CSS en :root: 

/* En assets/css/styles.css */
:root {
  --brand-color: #1a56db;  /* ← Cambia este color hex */
  --brand-hover: #1648c0;  /* ← Y este para el hover  */
}

/* Clase de botón corporativo */
.btn-brand {
  background-color: var(--brand-color);
  color: #fff;
  border: none;
}
.btn-brand:hover {
  background-color: var(--brand-hover);
  color: #fff;
}
